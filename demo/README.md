# The Great Dreamer Demo

> That is not dead which can eternal lie,
> and with strange aeons even death may die.

## Installation

1. Open the **Extensions** view in VS Code or Cursor
2. Search for `great-dreamer` and click _Install_
3. Pick **The Great Dreamer** under *Preferences: Color Theme*

See the [Open VSX listing](https://open-vsx.org/extension/rgsx/great-dreamer) or the [README][readme].
